**Prompt: Bootstrapping the app**

```
You are generating the first UI for an insurance-agnostic, AI-powered healthcare navigator.

Goals:
- Next.js + TypeScript + Tailwind + React Hook Form.
- File routes with app/ directory.
- Strict typing via shared models (can inline for now).
- No PHI. Educational-only disclaimers visible.

Create:
1) A landing page at `/` with:
   - Hero: "Find Medical Care” and subtitle: "Find the right care with location-aware, voice-enabled search—powered by trustworthy public data.”.
   - Primary CTA panel (“Find care”) that enforces either geolocation permission or a ZIP code, then enables voice or text query.
2) A results page at `/results` that reads query params and renders a provider list.

Non-functional:
- Accessibility: labels, aria, focus management.
- Mobile-first, responsive.
- Dark-mode support.
- Analytics placeholders only (no tracking code).
- Environment-safe: no secrets in client code.

Project structure (high level):
- app/(marketing)/page.tsx                 -> hero + CTA
- app/(search)/results/page.tsx           -> results rendering
- components/SearchPanel.tsx              -> location + query UI
- components/VoiceButton.tsx              -> mic UX (start/stop, permission states)
- components/ProviderList.tsx             -> list + cards
- lib/models.ts                           -> Provider, SearchQuery schemas (zod)

Include basic unit tests for components with Vitest + Testing Library.

Acceptance criteria:
- If geolocation denied and ZIP empty -> Search button disabled with inline helper text.
- Voice button toggles recording; transcript appears in input; user can edit before searching.
- Submitting navigates to /results?zip=…&lat=…&lng=…&q=…&mode=voice|text.
- Results render provider cards with name, specialty, distance, address, verified badge.
- Empty + error states present.

Add a footer banner with a short disclaimer: “AI-generated guidance is for education only. Not medical advice.”
```

# 2) Location Capture UI

**Prompt: Build the SearchPanel with location prerequisites**

```
Create components/SearchPanel.tsx.

UX requirements:
- Step 1: Location
  - “Use my location” button -> tries navigator.geolocation.getCurrentPosition with highAccuracy.
  - If granted -> show city/approx distance via reverse-geocode placeholder (don’t call external APIs; show “Location on”).
  - Or ZIP input with mask/validation, title="ZIP Code", placeholder="e.g., 60601".
- Enforce: At least one of (geolocation OR valid ZIP) is active, or Search disabled.

- Step 2: Query
  - Text input (multi-line allowed up to 500 chars) with char counter.
  - VoiceButton to capture speech: when recording, show animated mic + elapsed time; after stop, place transcript into text field.

- Submit
  - On submit, push to /results with URL params.
  - Include `mode` param (voice|text), prioritizing voice if transcript came from mic.

Accessibility:
- Use <label> for inputs; aria-live polite for validation and mic state.
- Keyboard: space/enter toggles mic; Esc cancels recording.

Edge states/messages:
- Geolocation denied → inline error with “Enter ZIP to continue.”
- ZIP invalid → inline helper “Enter a 5-digit ZIP.”
- Mic permission denied → inline note and keep text entry usable.

Styling:
- Clean card with subtle shadow, rounded-2xl, adequate spacing.
```

# 3) Voice Capture (Web Speech API or shim)

**Prompt: Implement VoiceButton with graceful fallbacks**

```
Create components/VoiceButton.tsx.

Responsibilities:
- Detect Web Speech API (`window.SpeechRecognition || webkitSpeechRecognition`).
- Provide states: idle, requesting-permission, recording, processing, denied, unavailable.
- Start/stop controls; return interim + final transcripts via onTranscript(text, isFinal) callback.
- Debounce interim updates for performance; accumulate final transcript.

UI:
- A toggle button with aria-pressed, a live region for status (“Recording…”, “Permission denied”, “Speech recognition unavailable”).
- Spinner/animation while processing.

Fallback:
- If API unavailable, render disabled state with tooltip “Voice search not supported in this browser.”

Export props:
- `onTranscript(text: string, isFinal: boolean): void`
- `onModeChange(mode: "voice" | "text"): void`
```
